# Converter

## Структура проекта

### main.py
запуск программы
связывает остальные модули

### config.py
расположение config.json
сохранение путей к папкам IN и OUT
загрузка созданных путей к папкам IN и OUT
выбор папок IN и OUT

### converter.py
FFmpeg-функции
приоритет файлов
имена готовых файлов
запуск конвертации

### watcher.py
следит за папкой IN
реагирует на появление новых файлов
